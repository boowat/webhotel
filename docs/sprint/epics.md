## Cara Pakai

- **Epic** = "Part of" di Notion — area fitur besar
- **Story** = user story ("As a ... I want ... So that ...")
- **Task** = "Children Tasks" di Notion, di-assign ke satu orang, dicentang kalau selesai
- Update task/story ini kapan aja progress berubah — bukan cuma pas standup
- Status: ⚪ Not Started · 🟡 In Progress · 🟢 Done · 🔴 Blocked

Tambah Epic/Story baru kalau ada export Notion baru. Task boleh ditambah bebas di bawah story yang relevan.
